# Alli-Trade
### A full-stack marketplace platform built for university students to safely buy, sell, and exchange goods and services within their campus community.

## Overview
### Alli-Trade is a web application designed to address a common problem faced by college students: finding an affordable, trusted way to buy and sell items locally. Existing solutions such as Facebook Marketplace and Craigslist often lack student-focused safety measures, campus-specific organization, and streamlined communication.

### To solve this, our team developed Alli-Trade, a university marketplace that allows students to create listings, search for items, communicate with buyers and sellers, and manage transactions within a trusted academic community.

## Features
### * Secure user registration and authentication
### * Create, edit, and manage marketplace listings
### * Image uploads and categorized listings
### * Search, filtering, and pagination
### * Direct buyer-seller messaging
### * Listing approval and moderation workflow
### * User profile and account management
### * Google Analytics integration
